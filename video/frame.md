# frame.md：开发者 AI 周刊视频（方案 B · 纸面编辑风）

所有期共用的视觉规范。`scripts/build.mjs` 生成的合成以这里为准；改风格先改这里，再改生成器。

## 概念

像在读一份有人用荧光笔批注过的周刊。纸面是底，原文是证据，红笔是编辑的判断。

## 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 纸底 | `#f5efe3` | 全片背景，不换 |
| 卡片纸 | `#fffdf8` | 浏览器窗口、卡片、字幕底 |
| 墨色 | `#2b2622` | 正文、标题 |
| 次要 | `#6f6355` | 说明文字、未激活项（对纸底对比度 ≥ 4.5） |
| 线 | `#d9cfbd` | 边框、横线 |
| 朱红 | `#b23a2e` | 唯一强调色：批注框、编号、重点柱 |
| 荧光黄 | `#ffd84d` | 荧光笔，只用在被讲到的那句话上 |

## 字体

- 标题：宋体 `Songti SC`，700。
- 正文、字幕、标签：苹方 `PingFang SC`，400 / 600。
- 网址、文件名：`JetBrains Mono`。

## 版式

- 画布 1920×1080。左上角是来源标签（栏目或原文域名），右上角是章节进度。
- 底部 150px 留给字幕：苹方 42px，墨色，卡片纸底，居中。
- 内容区 y 140–900，左右边距 ≥ 90px，内容贴左对齐，不做居中漂浮。
- 背景：纸底 + 横格线（12% 透明度，缓慢上移）+ 左侧一条朱红页边线。

## 动效

- 荧光笔：从左往右扫，0.5 秒，`power2.out`，多行依次扫。
- 批注框：朱红 3px 边框，轻微倾斜（−2°），从右侧弹入。
- 原文网页：页面滚动 0.9 秒 `power3.inOut`，停住后有极慢的推近，任何画面静止不超过约 6 秒。
- 每个场景开头 0.5 秒入场，结尾 0.35 秒淡出，背景不跟着切。

## 不要

- 不用渐变文字、霓虹色、深色底。
- 荧光黄不做大面积底色。
- 不放与口播无关的装饰文字。

## 单篇精读（`build-read.mjs`）

和周刊不同，单篇是全屏的原文网页，没有纸底、横格线、页边线和章节进度。色板、字体、荧光黄、朱红不变。

### 版式

- 浏览器窗口铺满 1920×1080，顶部是周刊同款 Chrome 栏，没有圆角和阴影。
- 页面推近到正文栏：倍数 = 1920 ÷（正文栏宽 + 两侧各 60 px），不超过抓取清晰度（3 倍）。
- 当前划线放在画面中段（Chrome 栏下 40 px 到字幕上方之间居中），译文块一起算进去。
- 字幕：位置、字号同周刊（苹方 42px），卡片纸底 95% 不透明，压在页面上。
- 红色批注：右上角，朱红 3px 框、40px 字、−2° 倾斜，宽不超过 720px。

### 一处划线

1. 撤掉上一处：缝合（0.4 秒）、聚光淡出，上一处荧光笔降到 32% 不透明。
2. 滚到这句（0.8–1.4 秒，按距离，`power3.inOut`）。
3. 聚光：这句所在段落以外压暗（黑 42%），0.4 秒。
4. 手绘荧光笔：SVG 笔迹，上下边缘不规则、两端圆头不齐、每行 < 1° 倾斜，种子是高亮 id，逐行从左往右扫（每行 0.45 秒，行间 0.26 秒）。
5. 裂开：页面从这句最后一行下方分成两层，下层下滑出译文块的高度（0.55 秒，`power3.out`）。译文块：苹方 44px（屏幕尺寸）、行高 1.5、卡片纸底、左侧 6px 朱红竖线，宽同段落；逐字写入，总时长 ≤ 1.1 秒。
6. 停住时极慢推近（2.2%），画面不静止。

### 其他

- 数字大字卡：页面压暗 62%，卡片纸卡上宋体 900 朱红 200px 数字 + 一行 46px 说明，`back.out` 弹出，停约 2.6 秒。全片最多 2 张。
- 配图放大：推近到图片铺满字幕上方，聚光圈住图片。全片最多 3 次。
- 结尾小卡：「开发者 AI 周刊 · #N · 精读」+ 周刊网址（JetBrains Mono 54px）+「原文与周刊链接都在简介里」，压在页面中间。
